# 智能问答助手

macOS 上的轻量答题辅助工具，支持页面题目和房间发言两种模式。页面模式从浏览器题区截图识别并可自动发送；房间模式监听 WebSocket 中指定玩家的发言，只生成答案并复制到系统剪贴板，不向房间或页面发送。

## 运行

```bash
python3 -m pip install -r requirements.txt
python3 app.py
```

首次运行需要给 Terminal/Python 授予“屏幕录制”和“辅助功能”权限，否则截图、窗口锁定或模拟输入会被 macOS 拦截。配置保存在 `question_agent_config.json`，日志保存在 `question_agent.log`。

## 使用顺序

1. 刷新并选择目标浏览器窗口，点击“保存当前位置”。以后可用“恢复固定位置”一键恢复，勾选“持续锁定”会自动保持该位置和大小。选择“并行运行”时，页面题目和房间发言会在同一个程序的两个独立线程中同时运行。
2. 填入 Model、Base URL、API Key。需要知识库时填写百炼知识库 ID 并勾选“启用知识库”；文字题会先检索本机的 23 份 PDF 和 2 份 Markdown，命中后用普通 Chat 快速回答，本地资料不足时自动回退百炼知识库。需要实时信息时勾选“启用联网搜索”，两者可以同时启用。房间模式如果要用 Gemini Google Search，请填写 `Gemini Base URL`、`Gemini Model` 和 `Gemini API Key`，并勾选“收到题目并行调用主模型 + Gemini 搜索”。该开关会在独立回答线程中调用主模型，主模型返回后立即复制；Gemini 在后台搜索，不会阻塞下一条房间发言，也不会打开 Chrome 搜索窗口。每个成功答案都会重新写入剪贴板，两路答案都会写入日志并标红。对 OpenAI 兼容代理，搜索参数使用 `web_search_tool`；官方 Gemini 地址则使用原生 `Interactions API`。开关在答题运行期间也可修改，从下一次模型请求起立即生效。“测试问答”可直接输入文字问题，勾选 Gemini 开关时也会走同一条 Gemini Google Search 流程。
3. 点击“显示红框”，拖动红框边缘或右下角手柄，让它包住题目文字；松开鼠标后题区位置和大小会立即保存，下次启动自动恢复。
4. 分别点击“拾取输入框”和“拾取发送按钮”，把鼠标移到对应位置中心，等待 2.5 秒记录；也可以直接修改相对窗口的 X/Y 百分比。坐标修改后立即生效，“显示点击标记”会在屏幕上标出两个位置 3 秒。
5. 点击“测试发送”可立即按当前坐标双击输入框、粘贴“测试”并点击发送按钮，不会调用模型。勾选“仅回答，不发送”后，真实答题仍会识别题目、调用模型、复制答案并记录答案，但不会执行任何点击、输入或发送；运行中切换立即生效。启用知识库时，日志会显示查询词、命中数、文件名、相似度和片段，答案行以红色显示。确认无误后点击“开始答题”。如需防止窗口被误拖动，可同时勾选“持续锁定”。

## 房间模式

1. 选择“房间发言”，填写房间号、房间密码和指定玩家的用户 ID 或完整昵称。
2. “机器人配置”默认读取同一 `kc-suite` 目录下 `websocket-bot/config.json`。登录参数失效时点击“更新登录”，专用 Chrome 会复用保存的登录状态，并自动更新 `login_token`、`login_device`、`login_p` 和 `login_z`；首次使用才需要登录。“编辑 JSON”仍可用于检查配置。
3. 依次点击“连接/登录”和“加入房间”，成功后再点击“开始答题”。“开始答题”只开启回答，不会重新登录或重新加入。服务器返回房间所属线路后，程序会固定该线路每 0.5 秒重试，房间满员时不会再轮换其他线路；意外断线后也会重连已确认的线路并继续尝试。
4. 指定玩家发言后，程序调用文字问答并把答案写入 macOS 系统剪贴板。该模式固定不发送消息，便于微信输入法把剪贴板同步到手机。
5. 房间模式勾选“收到题目并行调用主模型 + Gemini 搜索”后，5 个字以上的发言会调用主模型和启用 Google Search grounding 的 Gemini；不会新建 Chrome 窗口。每次主模型或 Gemini 成功返回都会重新复制答案，即使期间已经收到新题也不会跳过，便于手机端剪贴板同步。关闭该勾选即可只使用普通文字模型回答。

房间答题程序和页面题目程序可以同时运行，各自使用自己的运行状态；两者仍共享同一个 `question_agent_config.json`，同时运行时尽量不要在两个窗口里交替保存配置。当前已验证 `https://api.qnaigc.com/v1` 的 `gemini-3.5-flash-lite`、`gemini-3.6-flash` 和 `gemini-3.7-flash` 可用；追求速度时推荐 `gemini-3.5-flash-lite`，并使用 `web_search_tool`。`gemini-3.8-flash` 当前返回无可用通道。

默认模型和 Base URL 已按 Qwen 兼容接口预填。本地索引只提取 PDF 和 Markdown 文字，不读取图片、不做 OCR；首次生成可能需要约 20 秒，之后会从 `tmp/local_knowledge_index.json` 快速加载，源文件变化时自动重建。页面截图题仍使用原来的远端知识库。知识库或联网搜索启用后，远端回退使用百炼 Responses API；知识库需先在百炼创建，并建议把 Base URL 改为对应业务空间的专属地址。新题使用相邻两帧的本地像素结构确认，不再定时等待；变化阈值越小越敏感，题区动画较多时可适当调大。

验证核心图像变化逻辑：

```bash
python3 app.py --self-test
```
