# 玩家在线监控

输入一个或多个 SID（逗号或空格分隔）后立即并发查询玩家状态，之后每分钟查询一次。在线、离线时间范围会持久化保存到同目录的 `online_history.json`。

```bash
python3 app.py
```

程序每次请求都会读取 `../websocket-bot/config.json` 中最新的统一 `u` 参数。

检测到玩家进入新的在线区间时，程序会通过 `config.json` 中配置的企微群机器人 Webhook 推送一次上线提醒。通知失败会在下一轮自动重试。

接口请求失败、返回异常、玩家数量小于 1 或玩家数据为空时，都会发送查询异常告警；同一次连续异常只提醒一次，查询恢复后再次异常会重新提醒。

停止监控后可点击“清空历史”，确认后会清空所有玩家的本地在线、离线记录。
